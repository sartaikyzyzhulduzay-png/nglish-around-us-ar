# English Around Us AR Mini Dictionary

Күнделікті өмірде кездесетін ағылшын сөздерін сурет, қазақша аударма, айтылуы және мысал сөйлем арқылы үйренуге арналған веб-қосымша.

## Негізгі мүмкіндіктері

- 6 тақырыптық сөздік беті: Technology, Social Media, Fashion, Shopping, Food and Drinks, Entertainment.
- Сөздің ағылшынша жазылуы, IPA айтылуы, қазақша аудармасы және мысал сөйлемі.
- Сөзді тыңдау және келесі сөзге өту.
- Телефон камерасын қолданатын AR көрінісі; камера қолжетімсіз болса да, аудио жаттығу жұмыс істейді.

## Файлдар құрылымы

```text
.
├── index.html                  # Қосымшаның беті
├── app.js                      # Сөздер, камера және аудио функциялары
├── style.css                   # Негізгі стильдер
├── mobile-fix.css              # Мобильді түзетулер
├── assets/                     # Тақырыптық суреттер
├── .github/workflows/pages.yml # GitHub Pages жариялау workflow-ы
└── .nojekyll                   # GitHub Pages баптауы
```

## GitHub Pages арқылы іске қосу

1. Репозиторийде **Settings → Pages** бөлімін ашыңыз.
2. **Build and deployment** ішінен **GitHub Actions** таңдаңыз.
3. Өзгерістерді `main` тармағына жіберіңіз. `pages.yml` workflow сайтты автоматты түрде жариялайды.
4. Жариялану күйін **Actions** бөлімінен, сайт сілтемесін **Settings → Pages** бөлімінен тексеріңіз.

## QR, AR және аудио нұсқаулығы

1. Телефон камерасымен оқу материалындағы QR-кодты сканерлеп, веб-бетті ашыңыз.
2. Қажетті тақырып карточкасын таңдаңыз. Камера рұқсатын сұраса, рұқсат беріңіз.
3. Сөздің аудармасы мен мысалын қарап, **Next word** арқылы келесі сөзге өтіңіз.
4. **Hear the word** батырмасын басып сөз бен мысал сөйлемді тыңдаңыз.
5. Дыбыс болмаса, құрылғының медиа дыбысын тексеріп, бетті Chrome браузерінде ашыңыз. AR көрінісінен **×** батырмасымен шығуға болады.

Камера көрінісі құрылғыда ашылады; бейне жазылмайды. Камера қолжетімсіз болса, сөздерді аудио арқылы жаттықтыруға болады.

## Соңғы мобильді түзетулер

Соңғы жаңартулар QR-сканер көрінісінің мобильді құрылғыларда дұрыс ашылуын, сканер интерфейсінің басқа элементтерден оқшаулануын, AR бетінің мобильді орналасуын және аудионың жұмысын жақсартты.
